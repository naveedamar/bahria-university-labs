# Compiler Construction Labs

This directory contains lab assignments and practical implementations for the **Compiler Construction** course at **Bahria University**.

## 📌 Overview

The exercises focus on foundational concepts and algorithms across key phases of compiler design:

- **Lexical Analysis:** Tokenization, regular expression specifications, comment removal, and lexical error handling.
- **Finite Automata:** Transition tables and DFA drivers for validating identifiers, numeric formats, and block comments.
- **Syntax Analysis:** Recursive descent parsing, AST construction, and syntax error diagnostics.
- **Grammar Transformations:** Algorithms for left recursion elimination and left factoring.
- **Intermediate Representations:** Three-Address Code (TAC) generation, basic block partitioning, and Control Flow Graph (CFG) reachability.

## 🚀 Running the Code

All tasks are written in Python and rely solely on the standard library. Run any script directly:

```bash
python3 lab-<number>/task-<number>.py
```
